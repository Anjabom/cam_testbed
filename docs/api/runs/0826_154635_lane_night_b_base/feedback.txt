## 7. 요청

위 3·4절을 없애는 방향으로 `~/white_cam_ws` 의 코드를 고쳐 줘.

**규칙**

1. 수정 대상은 워크스페이스 코드다. 테스트베드(`~/cam_testbed`)는 재는 쪽이라 결과를 좋게 만들려고 건드리지 않는다.
2. **임계값을 느슨하게 해서 체크를 통과시키지 마라.** 값이 아니라 원인을 고친다. 측정 기준 자체가 이 영상·차량에 안 맞는다고 판단되면, 그 근거를 먼저 말하고 `scenarios/lane_night_b.yaml` 의 `checks:` 를 고치자고 제안할 것 — 말없이 바꾸지 않는다.
3. 2절에서 통과한 체크를 깨지 않는다. 하나를 고치다 다른 하나가 깨지면 그것도 보고할 것.
4. 고칠 곳을 정할 때 4절의 병목 단계부터 본다 — 거기가 실제로 주행에 반영되는 길목이다.

**고친 뒤 검증**

```bash
cd ~/cam_testbed
python3 -m tb.run run --scenario scenarios/lane_night_b.yaml --tag fix
python3 -m tb.run feedback <새로 생긴 실행 이름> --vs 0826_154635_lane_night_b_base   # 무엇이 좋아지고 무엇이 나빠졌는지
```

`lockstep` 이라 같은 코드면 값이 정확히 같다. 숫자가 바뀌었다면 그건 전부 코드 변경 때문이다.
